ℹ️ Come funziona
  1. Incolla uno o più link YouTube
  2. Clicca "Aggiungi Video" per ogni link
  3. Clicca "Riproduci Tutti" per avviare
  4. I video verranno scaricati in 480p
  5. Si apriranno a schermo intero sul secondo monitor
  6. Dopo ogni video, scegli se eliminare il file
