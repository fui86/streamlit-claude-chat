ℹ️ Come funziona
  1. Configura le impostazioni (qualità video e cartella download)
  2. Incolla uno o più link YouTube
  3. Clicca "Aggiungi Video" per ogni link
  4. Clicca "Riproduci Tutti" per avviare
  5. I video verranno scaricati nella qualità selezionata
  6. Si apriranno a schermo intero sul secondo monitor
  7. Dopo ogni video, scegli se eliminare il file
